# Source Map

## Root

| Path | Purpose |
|---|---|
| `CMakeLists.txt` | Build system: defines `data_ingestion` library, all test executables, `run_trainer` binary, and Metal kernel metallib compilation |
| `pretokenize.py` | Python script: reads Parquet dataset, tokenizes with tiktoken cl100k_base, writes flat uint32 `.bin` for C++ ingestion |
| `fix_metal.py` | Hot-patching script for `MetalBridge.mm` buffer cache — adds persistent buffer tracking; run after generated code modifications |
| `AGENTS.md` | Agent instruction guardrails for Cursor/Claude code mode |
| `CLAUDE.md` | Claude code mode instructions |
| `compile_commands.json` | Clangd/LSP compilation database (auto-generated by CMake) |

## `cpp/` — C++ Training Engine

### `cpp/include/` — Public Headers

| File | Concept | Key Types |
|---|---|---|
| `TransformerConfig.hpp` | Model hyperparameters | `ModelConfig` (vocab_size, hidden_dim, n_layers, n_heads, head_dim, ...), `KVCache` |
| `Tensor.hpp` | Multidimensional array | `Tensor` — shape, strides, data vector, matmul, transpose, element-wise ops |
| `Transformer.hpp` | Full model | `Transformer`, `TransformerLayer` — owns token_embeddings, layers, output_projection, final_norm, rope |
| `Attention.hpp` | GQA attention layer | `Attention` — Wq, Wk, Wv, Wo weight tensors; forward/backward |
| `RMSNorm.hpp` | Root Mean Square Normalization | `RMSNorm` — weight tensor, forward/backward |
| `Positional.hpp` | Rotary Position Embeddings | `RoPE` — precomputed sin/cos table, forward application |
| `Activations.hpp` | Activation functions | `silu` (SiLU/Swish), `swiglu` |
| `Loss.hpp` | Cross-entropy loss | `CrossEntropyLoss` — forward (loss scalar) and backward (grad_logits) |
| `Trainer.hpp` | Training loop orchestrator | `Trainer`, `TrainerConfig` — max_steps, warmup_steps, lr schedule, checkpointing |
| `Optimizer.hpp` | Optimization algorithms | `Optimizer` (base), `SGDOptimizer`, `AdamWOptimizer` |
| `DataIngestion.hpp` | Data streaming | `DataIngestion` — reads pretokenized .bin, yields batches of token IDs |
| `Checkpoint.hpp` | Model save/load | Checkpoint save/load to safetensors format |
| `gpu_kernel/MetalBridge.hpp` | GPU runtime bridge | `metal_bridge::` namespace: `initialize()`, `gemm_ffn()`, `gemm_proj()`, `gemm_gqa()`, RMS norm, backward kernels, AdamW step |

### `cpp/src/gpu_kernel/` — Metal GPU Kernels

| File | Role |
|---|---|
| `MetalBridge.mm` (53KB) | C++ ↔ Metal bridge — device init, buffer cache, pipeline states, all kernel dispatch functions |
| `gemm_ffn.metal` | Tiled GEMM for SwiGLU FFN (gate/up/down projections); 64×64 output tiles |
| `gemm_proj.metal` | Tiled GEMM for Q/K/V/O projections |
| `gemm_proj_trans_b.metal` | Projection GEMM with pre-transposed weights |
| `gemm_gqa.metal` | Fused GQA attention (Flash Attention-style — fuses softmax, no materialized S×S matrix) |
| `gemm_backward.metal` | GEMM backward pass kernels |
| `rms_norm_forward.metal` | RMSNorm forward pass |
| `rms_norm_backward.metal` | RMSNorm backward pass (dx and dw) |
| `swiglu_backward.metal` | SwiGLU activation backward |
| `rope_backward.metal` | RoPE backward pass |
| `gqa_backward.metal` | GQA attention backward pass |
| `adamw_step.metal` | AdamW optimizer step (GPU-accelerated parameter update) |
| `cross_entropy.metal` | Cross-entropy loss forward pass (GPU path) |
| `embedding_forward.metal` | Token embedding lookup (GPU path) |
| `residual_add.metal` | Residual connection addition |
